# Interactions

A collection of interactions rebuilt to look and move like their references. The page lists cards with only a number and a name; clicking a card opens the page for that interaction. Pages that are already on the main site ([ysh4267.github.io](https://ysh4267.github.io/)) are not listed here.

Live: https://ysh4267.github.io/interactions/

| No. | Name | Page | Source |
| --- | --- | --- | --- |
| 01 | Sidebar & Progress | [ref-stripe-sidebar](https://ysh4267.github.io/ref-stripe-sidebar/) | [Stripe](https://designspells.com/spells/animation-when-hovering-on-the-sidebar-toggle-in-stripe), [Things](https://designspells.com/spells/progress-indicator-animation-in-things) (Design Spells) |
| 02 | Dither Tiles | [ref-basedash-tiles](https://ysh4267.github.io/ref-basedash-tiles/) | [Basedash, Design Spells](https://designspells.com/spells/interactive-empty-state-graphics-in-basedash) |
| 03 | Vinyl | [ref-vinyl-player](https://ysh4267.github.io/ref-vinyl-player/) | [godly.design 616](https://cdn.godly.design/posts/616.mp4) |

## Notes

- The list lives only in `ITEMS` in `main.js`.
- Card pictures are stills in `previews/`. Hovering a card with a mouse plays that page's demo (`?demo`) inside the card; it is removed on leave.
- No build step: just `index.html`, `style.css` and `main.js`.
