# Interactions

A collection of interactions rebuilt to look and move like their references. The page lists cards with only a number and a name; clicking a card opens the page for that interaction.

Live: https://ysh4267.github.io/interactions/

## Notes

- The list lives only in `ITEMS` in `main.js`.
- Card pictures are stills in `previews/`. Hovering a rebuilt page's card with a mouse plays that page's demo (`?demo`) inside the card; it is removed on leave.
- No build step: just `index.html`, `style.css` and `main.js`.
